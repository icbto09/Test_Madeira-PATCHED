# One result per line, fields split by " | ":
#   keys | title | device | tier | build | summary | source | last good | first good
# keys:   comma-separated: steam:<app id>, exe:<program file name>, title:<game title> (lower case)
# device: iPhone, iPad or unknown (the record did not say)
# tier:   runsWell, runsWithFixes, runsWithProblems, startsOnly, doesntRun
#         runsWithFixes: worked with fix lines. Every runsWithFixes game needs its lines shown in the app:
#         Madeira's own list for it (GameRecommendations.swift) or a "hand" line below
#         (tests/host/check-run-status.py fails otherwise)
# hand lines: hand | <one of the game's keys> | <config line the player adds by hand> | <source>
#         shown in "Why this rating" as "Add by hand: <line>"
# title keys only match games from outside Steam (the app rates a Steam copy by its app id)
# source: where the proof is (record file and line). A result without one is refused.
# last good / first good: builds, or - when the record has none.
#
# Rule: only results a record proves. No proof = leave the game out (the app shows Not tested yet).
